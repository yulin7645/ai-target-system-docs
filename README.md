# AI目标作战系统 · 设计文档和标准

这里是 AI目标作战系统的设计文档和工程标准：学生目标怎么定、考情怎么拆、题目怎么标、统计结论怎么算。按这些标准，任何人都能拆卷、统计，结果可以互相接上。

## 文档

| 文档 | 讲什么 |
|---|---|
| `docs/02-PRD.md` | 产品需求：三个模块分别解决什么问题 |
| `docs/03-VI标准.md` | 视觉规范 |
| `docs/04-兴趣与信心测评设计.md` | 兴趣、信心两个测评的题目和计分 |
| `docs/05-PRD-考点梳理.md` | 考点体系 |
| `docs/10-备考方法论.md` | 备考方法 |
| `docs/13-题库数据结构设计.md` | 试卷、题目、地区考情三层数据结构 |
| `docs/14-考情指南标准.md` | 考情页面每部分回答什么问题 |
| `docs/16-工程规划-积木化与全国上线.md` | 积木化：每块只读上游的标准数据、只写自己的标准数据 |
| `docs/17-资料资产标准与兜底方案.md` | 每类资料分四级，缺了怎么兜底 |
| `docs/18-考情与学生目标衔接-讨论稿.md` | 学生目标怎么落到考情上 |
| `docs/31-机构题库入库指南.md` | 自己的卷怎么写成标准格式 |

## 标准文件

| 文件 | 内容 |
|---|---|
| `assets/kp-dict.json` | 考点字典：初中 9 科、高中 9 科，每个考点属于哪个模块、哪个年级 |
| `assets/fields.json` | 领域表：模块归到哪个领域 |
| `assets/README.md` | 工程资产清单和版本记录 |
| `scripts/bank/tag/facets.json` | 题目要拆成哪几项、每项能取哪些值 |
| `scripts/bank/guide/rules.json` | 考情结论怎么算（几年算固定、多少分算升温） |
| `scripts/bank/check_paper.py` | 试卷格式检查（Python 标准库，不联网） |
