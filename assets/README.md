# 工程资产（v0.3）

> 2026-11-14 起，项目「以工程资产为核心推进」：有价值的是这套标准，执行它的代码和模型都可以换。任何人（我们、其他模型、以后的学生）按这套标准拆卷、统计，结果都能直接接进系统。每次发布都对应一个资产版本。

## 生成一个地区的考情

```bash
npm run --silent bank:ingest                                        # 新卷入库后：补题组、字段、试卷表
python3 -I scripts/bank/guide/region_stats.py 中考 math 成都          # 生成地区考情表
python3 -I scripts/bank/guide/check_stats.py                        # 检查全部地区考情表
```

## 模型调度规程

### 谁做什么

| 工作 | 交给 | 并发 | 为什么 | 检查 |
|---|---|---|---|---|
| 统计、趋势、题号稳定性、页面 | 纯代码 | — | 规则确定，结果可复现 | `check_stats.py` |
| 题目字段（难度、情境、课标主题等） | Jev | 256 | 有固定选项，同题两遍 96%–100% 相同；全库约 2 小时、约 7.5 美元 | `tag/check.py` |
| 核心素养、情境复杂度、情境来源、区域尺度、思想方法、化学任务 | dsh | 64 | 实测比 Jev 更接近参照答案 | 同上 |
| 考点标签复核 | Jev | 32 | 判断「这道题是否考这个考点」，低于 0.3 记可疑并剔除 | `verify.py` |
| 考点对应教材章节 | Jev | 32 | 从目录里选一个；把握度低于 0.6 的进人工复核 | 人工抽查 |
| 官方文件文字 | 本机识别 | 6 | 免费；表格对照原图整理 | 原图存档 |
| 官方文件要点 | dsh | 64 | 是概括，原文同时附上，能对照 | 人工抽查 |
| 定标准、写规则、做参照答案 | 强模型 | — | 一次性决策，值得花成本；不做批量 | — |

### 选 Jev 还是 dsh

- **默认 Jev**：凡是「从固定选项里选一个」的工作。它最稳、最快，费用很低。
- **改用 dsh**：要读全文、写概括，或者实测 dsh 明显更准（比 Jev 更接近参照 5 个点以上，专业判断类 3 个点）。
- **新加一个字段**：两个模型各跑两遍，再用强模型做 200 题参照，按上一条决定，把结果写进 `routing.json`。

### 出错怎么办

- Jev 一个通道失效（额度用完、认证失败、限流），自动换到另一个通道。
- dsh 一次失败重试 3 次，还失败就跳过，记进失败清单，下次重跑会接着做。
- 连续失败 20 次就暂停整批，先查原因。
- 生成结果过检查：错误的不能用；只有提醒的可以用，页面上要写明（比如「只有 2 年真题」）。
