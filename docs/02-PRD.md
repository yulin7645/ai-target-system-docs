## 0.0 v2 → v3 改了什么（2026-10-28 用户反馈）

| # | 决定 | 说明 |
|---|---|---|
| E1 | **只服务中考、高考** | 理论依据是《中高考冲刺手册》，小学不适用：去掉小学学段与小学示例。 |
| E2 | **不再选「目标考试」与考试日期** | 初中即备考中考，高中即备考高考；月考 / 期中等日常考试只作为「最近一次成绩」的来源。 |
| E3 | **学生档案独立** | 称呼、年级（含学段）、所在地区、选科属于学生基础信息，用于记录学生情况、支撑后续分析；与「定目标」分开呈现。 |
| E4 | **考试模板按地区细化** | 中考按城市（各地自主命题、分值差异大），高考按省份（3+1+2 / 3+3 / 文理分科）+ 选科组合生成科目与满分；预设尽量多，标注依据年份，可手改。 |
| E5 | **沉浸式建档** | 新建学生走全屏、一屏一问的独立流程（参考 Apple 设置助理）：每屏只有一个问题、字段尽量少、一句话说明这项填写的用途；不再出现「左边填、右边空表」。填完生成目标后进入「目标总览」。 |

### 沉浸式建档的设计原则
1. **一屏一事**：每屏只回答一个问题；同类数据（各科成绩）可以在同一屏，但不混入其他概念。
2. **告知用途**：标题下用一句话说明「这一项会用来做什么」，不写说服性话术。
3. **少输入多选择**：年级、地区、选科用大卡片点选；分值由模板带出，只在需要时修改。
4. **始终可回退**：顶部分段进度（学生档案 · 成绩 · 目标），随时上一步；中途关闭会保存进度，下次从断点继续。
5. **键盘友好**：回车 = 继续；首个输入框自动聚焦。
6. **结果单独呈现**：最后一步「生成目标」后才出现目标总览，总览上每一块都能点「修改」回到对应那一屏。

### 流程（v3）
```
学生档案                         成绩                    目标
① 称呼 → ② 年级 → ③ 地区 → ④ 选科(高中) → ⑤ 科目与满分 │ ⑥ 最近成绩 → ⑦ 保底 A │ ⑧ 目标总分 C → ⑨ 兴趣 → ⑩ 冲刺分配 → ⑪ 信心 → 生成目标
                                                                                              ↓
                                                         目标总览 → 规划书
```

## 1. 产品定位

一个以规划师身份工作的 AI 提分系统。本期的「定总分目标」要做到：

- **标准化**：同一套字段、同一套规则，任何学生走一遍得到的结构一致。
- **可操作**：一步一个问题，10 分钟内填完；每一步都能回退修改，结果实时联动。
- **可解释**：每个目标数字都能在图上看出它是怎么来的（A 在哪、C 在哪、信心让 B 落在哪）。
- **闭环**：填写 → 目标 → 导出规划书；每次考完记一次成绩，目标滚动更新。

使用者：学生本人（主导填写）或家长陪同。

## 3. M1 定总分目标

### 3.1 流程

```
规划师引导填写（6 步）  →  目标总览  →  导出规划书
   ① 基本信息                A / B / C        识别每题 → 归到模块        总提分 → 学科 → 模块 → 知识点
   ② 各科成绩                子弹图           人工确认识别结果
   ③ 目标总分（志愿线）
   ④ 学科兴趣
   ⑤ 冲刺分配（系统建议，可调）
   ⑥ 达成信心
```

界面结构：左侧是规划师引导（当前这一步的问题与输入），右侧是实时生成的「目标成绩表」。每填一项，右侧立即更新。

### 3.2 第一段：定出 A / B / C 目标

**① 基本信息**
- 学段 / 年级、本次目标考试（期中 / 期末 / 中考 / 一模 / 高考……）、考试日期。
- 考试模板：选地区或学段模板后自动带出科目与满分，可增删科目、改满分。

**② 各科成绩**
- 每科填最近 1–3 次成绩（至少最近一次）。
- 系统给出 **A 保底** 建议值 = 最近一次成绩；可手动改为「我认为的真实水平」。
- 有 2 次以上成绩时显示波动区间（小折线）。

**③ 目标总分**
- 填第一志愿（可选）与往年录取线，或直接填目标总分 → 作为 **C 冲刺总分**。
- 校验：C 总分 ≥ A 总分；C 总分 ≤ 满分总和 × 95%（超出则提示「接近满分」）。

**④ 学科兴趣**：每科 1–10。

**⑤ 冲刺分配**
- 系统建议：把（C 总分 − A 总分）按「可提升空间 × 兴趣」比例分到各科（可提升空间 = 满分 × 95% − A；超过上限的科目封顶，余量继续分给其他科）。
- 用户可以改任意一科的 C；改后显示与目标总分的差（高于 / 低于 X 分），由用户决定是否保持。
- 视觉：兴趣条与分到的冲刺增量并排，一眼看出「兴趣越高分得越多」。

**⑥ 达成信心**：每科 1–10（对补上 A→C 差距的把握）。

**计算**（与手册一致）

| 字段 | 规则 |
|---|---|
| 差距 | C − A |
| 提升分 | round(差距 × 信心 ÷ 10) |
| B 核心目标 | A + 提升分（下一次考试的靶心） |

**合理性标签**（只出标签，不出长文）

| 条件 | 标签 |
|---|---|
| C > 满分 × 95% | 接近满分 |
| 信心 ≤ 3 | 信心偏低 · 建议设小目标 |
| 提升分 < 该科近几次成绩的波动幅度 | 在正常波动内 |
| C 总分 < A 总分 | 无法计算（阻止下一步） |

**目标总览的可视化**
1. **总分阶梯**：0 — 满分总和的标尺上标出 A、B、C 三点。
2. **各科子弹图**：满分轨道上标 A、C，A→C 之间按「信心 ÷ 10」的比例填充，填充终点就是 B——公式直接画在图上。
3. **提升分构成**：总提升分按学科堆叠。
4. 目标成绩表：学科 / 满分 / A / 兴趣 / C / 差距 / 信心 / 提升 / B。

### 3.3 ~~第二段：上传试卷 · AI 细化到模块~~（2026-11-15 已删除，见文首说明）

**目标**：把每科的提升分（B − A）落到具体的知识章节 / 题型模块，并给出依据题号。

**输入**：各科最近一次试卷照片（每科可多张）。剧本模式下示例档案自带试卷与识别结果，不调用 AI。

**AI 处理**（DeepSeek `deepseek-flash`，视觉）
1. 逐题识别：题号、题型、分值、得分、所属知识章节、可提升性（易 / 中 / 难）。先复述识别内容，**人工确认**后再计算。
2. 按模块汇总：该模块满分、得分、失分。模块口径按学科区分（数学 / 理化生按知识章节，语文 / 英语按题型）。
3. 分配：把该科提升分按「失分 × 可提升系数（易 0.8 / 中 0.5 / 难 0.2）」分到各模块，不超过模块的可追回上限。
4. 每个模块列出主要失分知识点与对应题号。

**口径与兜底**（2026-10-27 实测后补充）
- **标准模块表**：按「学段 × 学科」固定一套模块（`src/goal/templates.ts` 的 `modulesFor`），AI 只能从表中选，确认框给出下拉建议、非标准模块标黄。实测同一张卷 4 次识别的模块完全一致。
- **未识别部分**：照片里没拍到或看不清的部分，得分记为未知，不参与失分与可追回分计算；可在确认框手动补分。识别到的部分不足卷面一半时，提示「每页单独拍清楚后重新识别」。
- **稳定性**：结果无法解析或被截断时自动重试一次；单次识别约 12–30 秒，低清扫描件可达 60 秒（本地转发超时 150 秒）。

**输出：提分地图**
- 层级图：总提升分 → 学科 → 模块（宽度 = 分值）。
- 模块表：模块 / 当前得分 / 满分 / 目标得分 / +分 / 依据题号 / 可提升性。
- 未上传试卷的科目显示「待上传」，不影响其他科目。

### 3.4 输出：总分目标规划书
- 一页 A4：学生信息、目标考试、A / B / C 总分阶梯、各科目标表、各科子弹图。
- 浏览器打印为 PDF。

### 3.5 示例档案
3–5 份，覆盖高中偏科、初三中考、初二常规、小学六年级、高三。数据要合理，不再硬套 PPT 数字。可「新建空白档案」。
