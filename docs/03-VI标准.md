# AI目标作战系统 · VI 标准 v1（方向 B：极简专业）

> 2026-10-27 · 选定依据：[design/mocks/b-极简专业.png](../design/mocks/b-极简专业.png)
> 代码落地：`src/vi/tokens.css`（所有颜色、字号、间距只从这里取）

## 1. 气质

专业、克制、可信。像一个高水平规划机构的工作台：信息密度适中，数字是主角，装饰为零。

- 用：留白、细线、对齐、数字层级、单一品牌色。
- 不用：渐变、霓虹、发光阴影、emoji、卡通插画、大圆角胶囊堆叠、彩虹学科色。

## 4. 栅格与间距

- 设计基准 1920×1080；内容区左右边距 48；左右两栏：左 600（规划师）+ 间距 40 + 右自适应（目标表）。
- 4 点栅格：4 / 8 / 12 / 16 / 24 / 32 / 40 / 48。
- 圆角：卡片 8，输入框 / 按钮 6，刻度方块 5，标签 4。
- 阴影：仅 `0 1px 2px rgba(15,17,21,.04)`；浮层 `0 12px 32px rgba(15,17,21,.12)`。

## 6. 图表

统一三种标记，全站一致：

| 标记 | 样式 | 含义 |
|---|---|---|
| ○ 空心圆 | 白底 + ink-2 描边 | B 保底 |
| ● 实心圆 | 品牌蓝 | B 核心目标 |
| ◆ 菱形 | ink 黑 | S 冲刺 |

- **总分阶梯**：0 — 满分总和的标尺，A→C 区间填品牌浅，A→B 填品牌蓝。
- **子弹图**：满分轨道（line-2）上同样的三种标记；A→B 实线的长度 = (C − A) × 信心 ÷ 10，公式即图。
- **提分地图**：两级流向图（学科 → 模块），宽度 = 分值；品牌蓝的明度区分层级，不用多色。
- 刻度与标注用 ink-3，12px；数据标注用等宽数字。

## 7. Logo 与命名

- 标志：40×40 黑色方块，白色「AI」，无圆角或 2px 圆角。
- 产品名：「AI目标作战系统」，下方英文 TARGET PLANNING SYSTEM（11px，字距 0.24em，ink-3）。
- 模块名：定总分目标 / 考点梳理 / 答题程序 / 冲刺计划。

## 8. 文案

- 规划师提问：一句话，以「你」称呼，不超过 30 字。
- 允许：提问、字段名、单位、填写要求、规则公式、状态标签、数据来源标注。
- 禁止：讲稿、说服性话术、营销承诺、直播口令、长段解释。
