## 0. 一页结论

| 项 | 决定 |
|---|---|
| 定位 | 作战系统第二步。展示两种能力：**AI 实时检索**（DeepSeek 联网搜索）和**系统沉淀的题库**（各地历年真题的考点标签）。核心价值不是知识点清单，而是让学生觉得「这是专门为我做的考点作战方案」 |
| 和外面的区别 | 练习册与通用 AI 给的是千篇一律的考点表；这里每一屏都写着「你」：你的城市 / 省份和试卷、你的目标分、你的试卷失分点、你自己点亮的掌握情况 |
| 数据来源 | ① 真题库：首期**数学**，12 城中考 + 高考各卷近 5 年，从公开原卷图片 / CC BY 原卷 PDF 拆题，带题图和考点标签（见 06 v3）；② 联网：DeepSeek Search API（已实测，每 1000 次 5 元）；③ 整理：deepseek-flash 按固定格式输出。商用题库（已提交资料）留给第三步出题 |
| 入口 | 系统按第一步的提升分和本地考频，排出「建议先查」的科目和模块，学生可改；一次检索一个科目的一个模块 |
| 结果 | 两层：**必拿分作战图**（整卷视角，题号 → 必拿 / 争取 / 放弃，合计等于目标分）+ **我的考点地图**（模块视角，考频 × 掌握度） |
| 结果内容 | 考点星级表 · 我的掌握情况 · 必拿分题号表 · 典型真题示例 |
| 考频口径 | 星级与高 / 中 / 低频按近 5 年算，同时显示「近 10 年考了几次」 |
| 7:2:1 | 显示该地该科的**真实**分值占比（题库统计），旁边标「常见比例约 7:2:1」 |
| 掌握情况 | 学生自己点亮（会 / 不稳 / 不会）为准；以后由「学情」积木按上传的试卷给出参考 |
| 作战目标 | 默认该科冲刺分 S（中考 / 高考那天），可切到下一次的 A |
| 没学到的 | 每个考点标年级；没学到的灰显，必拿分里单独列「学到后再拿」，不计入掌握率 |
| 题库未收录的科目 | 只出考点地图（实时检索），作战图显示「题库建设中」，不推断题号 |
| 检索过程 | 可视化展示：读取学情 → 检索题库 → 联网检索（来源卡片）→ AI 整理 → 个性化 |

## 1. 页面结构

导航第二个模块「考点梳理」开放，进入后沿用学生档案头（姓名 · 年级 · 考试 · 目标学校）。

### 1.1 考点梳理首页

1. **为你定制**抬头：「为 陈思远 定制 · 南京中考 · 冲刺 615 / 下一次 586」。
2. **题库覆盖**条：「已收录：数学 · 12 个中考城市 + N 套高考试卷 · 2017–2026 · 共 X 套试卷、Y 道题、Z 个考点标签」。数字由题库实时统计，没有的不写。
3. **建议先查**队列（3–5 条）：
   - 格式如「数学 · 二次函数｜冲刺还差 +21 · 上次试卷这里丢了 12 分 · 南京近 5 年每年都考」。
   - 排序 = 该科提升分 × 模块考频（有题库时）。
4. **科目切换**：笔试科目按提升分排序；体育、实验等单独设定的科目不出现。

### 1.2 科目页

- **必拿分作战图**（题库已收录的科目）：
  - 底图是当地最近一年试卷的结构：选择、填空、解答，按题号和小问排开。
  - 每个格子显示：题号、典型考点（近 5 年这个位置最常考的）、分值、难度。
  - 每个格子着色：**必拿**（深蓝）/ **争取**（浅蓝）/ **可放弃**（灰）/ **学到后再拿**（虚线）。
  - 顶部算账：「必拿 85 + 争取 18 = 103 = 你的数学冲刺分」。切到 A 时只亮出下一次先拿的部分。
  - 点格子看：这个位置近 10 年考过什么、你在这个考点的掌握情况。
- **分值占比**：高 / 中 / 低频的真实分值占比环形图，标注「常见比例约 7:2:1」。
- **模块列表**：标准模块表，每个模块显示考频星级、你的点亮进度、是否已检索。点模块进入检索。

### 1.3 检索过程（模块，约 15–40 秒）

每一步都写真实的东西，出完一步打勾：

1. **读取你的学情**：年级、地区与考试、该科 B / A / S、兴趣与信心、试卷失分点（有就列出）。
2. **检索系统题库**：「南京中考数学 2017–2026 · 10 套 · 二次函数相关 37 道小题」。没收录时写「本地区暂未收录，转联网检索」。
3. **联网检索**：
   - 并发 2–4 个查询（如「南京 中考 数学 二次函数 考点 after:2021」）。
   - 结果以来源卡片逐张飞入：站点、标题、日期，只保留高相关度的结果。
4. **AI 整理考点**：按固定格式生成考点、星级、考查方向、复习建议、典型真题。
5. **为你个性化**：结合目标分和掌握情况，选出 3–5 个优先突破点。

### 1.4 模块结果：我的考点地图

- **主图**：考点卡片按「考频（纵）× 掌握度（横）」排列。
  - 右上「高频 · 没掌握」区高亮为「先打这里」。
  - 没学到的灰显。
- **点亮**：
  - 学生点一张卡片，在「会 / 不稳 / 不会」之间切换，有点亮动效。
  - 顶部进度：「已点亮 12 / 18 · 高频考点掌握 58%」。
  - 有试卷证据的卡片带标记：「上次试卷第 19 题在这里丢了 6 分」，点亮时作为参考。
- **考点星级表**（可切换为表格）：
  - 列：考点、近 5 年考频（x / 5）、近 10 年（y 次）、星级、高 / 中 / 低频、核心考查方向、复习建议、年级、我的掌握。
- **优先突破**：3–5 个，每个写：
  - 为什么是它（频率、失分、离目标）。
  - 建议行动（做什么题、做多少）。
  - 对应作战图里的哪些题号。
- **典型真题**：每个高频考点 1–2 道，题干摘要 + 年份题号 + 出处链接（题库优先，联网补充）。
- **来源**：本次用到的题库试卷与网页，可展开查看。
- **说明**：每个结果都标注数据来源：题库统计，或 AI 根据联网资料整理。资料不足的写「频率待确认」，不编造。

### 1.5 保存与复用

- 结果存进学生档案：科目 → 模块 → 考点与掌握情况。
- 再次进入直接显示；「重新检索」走完整流程。
- 掌握情况点亮后即时保存，并更新作战图的必拿 / 争取着色。
- 示例档案预置一份结果（标「示例」），也可以点「重新检索」演示真实流程。

## 2. 规则

### 2.1 考频、星级、高中低频（题库科目）

- **星级** = 最近 5 个**收录年份**里出现的年数：5 年都考 5 星；4 年 4 星；3 年 3 星；2 年 2 星；1 年 1 星；没考过 0 星。
  - 收录不足 5 年的按比例折算：出现年数 ÷ 收录年数 × 5，四舍五入，至少 1 星。
  - 页面写明年份区间（如「南京 2020–2024」）；2025、2026 年原卷补齐后自动滚动。
- **高 / 中 / 低频**：4–5 星为高频，3 星为中频，1–2 星为低频。
- **真实分值占比** = 近 5 年各档考点所占分值之和 ÷ 总分值。

未收录的科目由 AI 根据检索资料给星级，并标注「AI 依据联网资料整理」。

### 2.2 必拿分作战图

1. **试卷结构**：取当地最近一年的试卷，拆到小问，每个小问带分值、难度和典型考点。
2. **目标**：该科冲刺分 S，或下一次的 A。
3. **分配**：
   - 依次把「已学到、性价比高」的小问划为必拿。性价比从高到低：易且高频 > 易 > 中且高频 > 中 > 难的第一问 > 难。
   - 一直划到累计分值达到目标的约 85%；再继续划为「争取」，直到累计达到目标；剩下的可放弃。
   - 掌握情况会调整顺序：同档内，点亮「会」的排前，「不会」的排后。
4. **展示**：必拿 + 争取的合计等于目标分；差几分时如实显示「还差 x 分，需要从难题里拿」。

### 2.3 优先突破点

优先级 = 考频 × 未掌握程度（不会 1、不稳 0.6、待验证 0.5、会 0.1）× 已学到，再结合试卷失分加权。取前 3–5 个，建议行动由 AI 写，必须对应具体题型和题号。

### 2.4 AI 输出格式（固定 JSON，前端校验）

```
{ "summary": "一句话：为你整理的南京中考数学「二次函数」考点…",
  "kps": [{ "name": "二次函数的图象与性质", "freq5": 5, "freq10": 9, "stars": 5, "tier": "高",
            "direction": "…核心考查方向…", "advice": "…复习建议…", "grade": "九年级",
            "examples": [{ "year": 2024, "no": "26(2)", "stem": "…不超过 60 字…", "source": "url" }],
            "basis": "题库统计 / 联网资料", "confidence": "确定 / 待确认" }],
  "priorities": [{ "kp": "…", "why": "…", "action": "…", "nos": ["26(1)", "22"] }],
  "sources": [{ "title": "…", "url": "…", "site": "…", "date": "…" }] }
```

- **提示词封装**：学生的年级、地区、考试与试卷结构、该科满分 / B / A / S、兴趣与信心、该模块的题库统计。
- **AI 的身份**：「有十年经验的该地区命题研究者 + 专属提分规划师」。
- **硬性要求**：不编造频率，资料不足标「待确认」；真题示例只能来自题库或检索结果。

## 3. 技术

- **后端**（`server/ai_server.py`）：
  - 新增 `POST /api/search`，转发 DeepSeek Search，密钥只在服务器。
  - Nginx 给 `/api/search` 单独限流（每 IP 每分钟 30 次）。
- **题库**（流水线见 06 v3 第 3 节，命令见 README）：
  - 原始数据在 `bank/`：`papers.json` 登记表、`raw/`（页图与识别缓存，不进构建）、`papers/`（逐题结果）。
  - `npm run bank:stats` 汇总到 `public/bank/`：`index.json` 覆盖数字，`math/<城市>.json` 考点频率与题号位置，`papers/` 逐题数据，`img/` 单题裁图。
  - 前端按需加载。
- **考点字典**：每个学段、每个科目一份标准考点表，挂在标准模块下。题库标签、AI 输出、掌握情况都用它对齐，才能计数和匹配。
- **检索并发**：每个模块 2–4 次搜索 + 1 次 AI 整理；失败可重试；同一模块 7 天内复用缓存（可强制重新检索）。

## 4. 不做的

- 只收历年中高考真题，不收模拟题、练习题；题图只展示单题裁图并署名出处。
- 题库未收录的科目不推断题号作战图。
- 不做题目训练、知识点讲解：那是第三步「答题程序」。
- 不排每日计划：那是第四步「冲刺计划」，这里的优先突破点会作为它的输入。

## 5. 验收

1. **题库链路**：南京中考数学（题库已收录）：
   - 作战图合计等于该科 S；切到 A 正确变化。
   - 7:2:1 显示真实占比。
   - 模块检索的过程 5 步都有真实数字和来源。
2. **实时检索链路**：广州中考物理（未收录）：只出考点地图，标「AI 依据联网资料整理」，有来源链接。
3. **低年级**：初二档案的九年级考点灰显，不计入掌握率。
4. **掌握情况**：点亮后作战图着色、掌握率、优先突破实时变化。
5. **线上**：全流程走查截图无报错；限流生效。
