# 题库数据结构设计 v1

> 2026-11-09。回答三件事：题目、知识点、试卷各要记哪些字段；有没有现成结构可用；这么多分类字段用哪种模型打。
> 字段清单的机器可读版在 `scripts/bank/tag/facets.json`，由 `gen-facets.py` 生成，改字段改那里。拆解模块在 `scripts/bank/tag/tag.ts`，模型在 `config.json` 里换。

## 0. 结论

1. **没有一份现成结构能整套拿来用，但每一块都有权威来源。** 表怎么搭，参考国际标准；字段取值优先用教育部课标和高考评价体系的官方说法；官方没有的，才用业内常见做法，并标明可以改。
2. **结构不是一张表，而是三组表：** 字典（知识点、字段定义）、事实（试卷、题组、题目、小问）、标注（模型判的结果，带版本，可重跑）。
3. **字段分三层：** 所有题都有的通用字段，按科目不同的字段，按学段不同的字段。54 种「学段 × 科目 × 题型」组合已遍历，没有缺取值的。
4. **按字段分工。** 分拣类字段和差距小的字段走 Jev，主观、专业且正常模型明显更好的字段走低价模型（第 7 节）。全部走配置，随时能换。
5. **三个问题已修：** 阅读、完形带上共享材料（题组）；认知要求改成三档；只考语言形式或背诵的题不再问情境；Jev 的「难」用判定线修正。

## 2. 表结构

分三组，对应之前定的「原始事实不改 / AI 标注带版本可重跑 / 模型结果随时重算」。

### 字典

| 表 | 记什么 | 说明 |
|---|---|---|
| 课标条目 | 课标版本、科目、层级、名称、上级 | 对应 CASE 的框架和条目 |
| 知识点 | 学段、科目、模块、**年级**、**知识类型**、说明、状态 | 现有 655 个考点沿用，补知识类型 |
| 知识点 ↔ 课标 | 多对多 | 让知识点能追溯到官方依据 |
| 知识点 ↔ 教材 | 教材版本、年级、学期、章节 | 现在年级只按人教版，各地顺序不同，靠这张表解决 |
| 知识点关系 | 前置、包含 | 对应 CASE 的关联关系，以后用 |
| 字段定义 | 名称、层级、单选或分档、适用范围、来源、版本 | `facets.json` |
| 字段取值 | 名称、定义、顺序、来源 | `facets.json` |

### 事实（读卷得到，不随模型变）

| 表 | 记什么 |
|---|---|
| 试卷 | 考试、年份、科目、地区、满分、时长，以及第 5 节的试卷字段 |
| 试卷来源 | 文件、网站、链接、来源质量、内容摘要、入库时间。一套卷可以有多个来源 |
| 试卷 ↔ 地区 | 哪些地区用这套卷（现有出卷地图） |
| 大题 | 标题、顺序、题数、分值 |
| **题组（新增）** | 共享的文章、图表或材料，它们对应的题号。题组有自己的字段（语篇类型、主题语境、文本类型、材料形式） |
| 题目 | 题号、题干、题型、分值、裁图、是否有图 |
| 小问 | 小问号、分值 |

### 标注（模型或人判的，可以重跑）

| 表 | 记什么 |
|---|---|
| 标注批次 | 模型、提示词版本、字段版本、时间、费用 |
| 标注结果 | 对象（试卷 / 题组 / 题目 / 小问）、字段、取值、把握度、批次 |
| 题目 ↔ 知识点 | 对象、知识点、主次、批次 |
| 复核结果 | 谁复核、改成什么、依据 |
| 当前结果（视图） | 每个对象每个字段现在用哪个值：人工复核优先，其次最新批次 |

**统一输出：** 下游只读「当前结果」。换模型只是多一个批次，结构不变。现在的拆解输出已经是这个形状：`{ facts, facets: { 字段: { value, confidence } }, tagger }`。

## 6. 分批入库

新卷读完后跑一条命令：`npm run bank:ingest`（加 `-- --dry` 只看要处理哪些）。

它会找出没拆解过或卷子变动过的卷，依次提取题组、打新字段、更新试卷字段表，并把这批的数量和耗时记到 `bank/ingest-log.jsonl`。

- **可以反复跑**：已经做过且没变的卷不重复处理。
- **互不影响**：一套卷失败不影响其他卷，下次重跑接着做。
- **不影响线上**：只更新 `bank/` 里的结果，不重新生成页面数据，也不部署。页面数据仍走 `bank:stats`。
- **闸门沿用 `gate.ts`**：卷子不完整也收，按覆盖率算。只有地区对不上或一道能用的题都没有时才挡住。

**还没做的：** 同一套卷来了更好的来源时的替换规则，目前按读卷流程原有的方式处理。

**分工规则：** 分拣类字段，低价模型接近参照的程度比 Jev 高 5 个点以上才换；主观、专业类字段，高 3 个点以上就换；其余用 Jev，因为它结果稳定、速度快。知识类型（给考点字典分类）是分拣类，用 Jev。

**参照有偏向：** 低价模型和参照都是一次看整张卷、用同一个提示词，Jev 是一题一问，所以参照天然更接近低价模型。Jev 的实际表现可能比表上略好。参照本身也可能错。

**思想方法要留意：** 三者都不稳定，低价模型两遍只有 60% 相同。这个字段的结果先不用于对外结论。

**Jev 有两个通道：** TypeSafe 官方和 OpenRouter，`tag.ts` 和 `jev` 命令自动轮换。额度或认证问题，这个通道停用一小时；限流或服务问题，短暂冷却后再回来。

### 三个修复

| 问题 | 修法 | 结果 |
|---|---|---|
| 看不到共享材料 | 新增题组（`bank/groups/`，脚本 `groups.py`，不用模型）。Word 卷取原有材料；扫描卷从文字识别结果里找题与题之间的文字；题干「据此完成下面小题」连起来 | 英语阅读约 70%、完形约 71%、语文现代文约 50%、文言文约 61%；地理 65% 的题进了题组。没对上的题按单题判 |
| 认知要求分不清 | 四档合成三档，并写清每档的判定标准 | Jev 和低价模型接近参照的程度升到 74%–76% |
| Jev 不判极端档 | 保留概率，「难」的概率到 0.25 就判难 | 「难」从 34 道增加到 85 道，参照判 114 道 |

判定线只改取值，概率都保留，以后改线不用重跑。

### 全量结果（2026-11-09）

- 4035 套卷、约 11 万道题全部完成，题数对不上、卷子比结果新的都是 0。用 `python3 -I scripts/bank/tag/check.py` 可随时复查。
- 模型判断的字段里，由 Jev 判的 100% 有值；由低价模型判的 98.7%–99.9% 有值，缺的主要是个别化学卷。

- 655 个考点的知识类型已分类完（`bank/annotations/v1-p2-kp/`）。
- 第一轮中途 OpenRouter 余额用完（402），第二轮起走官方通道。结果里的模型版本因此有两种写法，都是 Jev 1.14。
- 批量并发：dsh 64，Jev 256。

- 除人工抽查外，比的都是彼此像不像；真实准确度还要靠人工标注样本或真实得分率。

## 8. 部分卷和多来源

- **闸门**（`gate.ts`）：只挡卷子和地区对不上、一道能用的题都没有的卷。严格校验 `check.ts` 仍保留，修卷工具继续用。
- **覆盖率**：按题号、大题说明和同卷种题量算；题不全且分值可信时，取分值和题数里较小的一个。
- **单题清理**：标签不在字典里的考点去掉；一个考点都不剩的题不进统计。
- **多来源合并**：同一套卷有两个来源时，题干相近的算同一题，保留已有的，多出来的补进来（`gk/xkb2word.py --merge`）。公式多的题比不出来，不新增，避免重复。

## 9. 地区考情统计（第三层，2026-11-14）

字段放在哪一层，按「会不会随城市变」来分：

| 层 | 放什么 | 存在哪 | 随地区变吗 |
|---|---|---|---|
| 知识点 | 在哪一册学、所属领域、知识类型 | 考点字典、`bank/kp-textbook.json` | 不变，全国一份 |
| 题目 | 题号、分值、题型、考点、难度、情境等 | `bank/papers/`、`bank/annotations/` | 跟着卷子走 |
| **地区考情** | 多年汇总后得出的结论 | `bank/region-stats/<考试>-<科目>-<地区>.json` | 每个地区每科一份 |

地区考情由 `scripts/bank/guide/region_stats.py` 从前两层算出来，不手写；判断规则在 `scripts/bank/guide/rules.json`，所有地区共用。新卷入库后重算一次。页面（`v3.py`）只读这张表，不再自己算结论。

**表一 kps（地区 × 考点）：** 每个考点一行，全部考点都列，没考过的也在。

| 字段 | 含义 |
|---|---|
| kp、module、field、book、chapter | 考点名、模块、领域、册别、章节（来自知识点层） |
| tested、tested_window、window | 全部年份里考了几年；近 window 年里考了几年 |
| freq | 近 5 年都考 / 常考（至少 3 年）/ 偶尔考 / 近 5 年没考 / 没考过 |
| trend | 升温 / 降温 / 新出现 / 近两年没考 / 稳定 |
| recent_avg、before_avg | 近两年、之前三年的年均分 |
| avg、n、share、main_diff | 考到时平均分、题数、占全部年份总分比例、主要难度 |
| yearly | 每年分值、题数、难度 |
| occurrences | 每次考到的年份、题号、小问、分值、难度 |

**表二 slots（地区 × 题号）：** 只用卷面结构和最新一年相同的年份。

| 字段 | 含义 |
|---|---|
| no、type、points | 题号、题型、分值 |
| stability | 考点固定 / 模块固定 / 每年换考点 / 部分重复 |
| top_kp、top_kp_years、top_module、top_module_years、kinds | 最常考的考点和年数、最常见的模块和年数、出现过几种考点 |
| diff_trend | 一直基础 / 一直中档 / 一直难 / 近两年变难 / 近两年变容易 / 有起伏 |
| new_kp | 最新一年出现的新考点 |
| cells | 每年的考点、模块、分值、难度 |

另有 modules（各模块每年分值和变多变少）。

**官方文件：** 原网页和图片存在 `bank/guides/official/<地区>/`，原文全文（网页正文加图片文字识别）存在同目录 `.txt`，索引在 `bank/guides/official-<考试>-<科目>-<地区>.json`，每条有原链接、要点、全文。
