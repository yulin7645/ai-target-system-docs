# 考情指南标准 v4（考生版：试卷和考点两条主轴）

> 2026-11-10。考情指南是给考生和家长看的「情报」，不是数据报告。这一层只管**输出什么、需要什么输入**；输入从哪来、准不准，是上一层（信息源和题目拆解）的事，这里只标明缺什么。
> 生成脚本：`scripts/bank/guide/build.py`（统计）→ `verify.py`（Jev 核对考点标签）→ `student.py`（考点分档和趋势）→ `v3.py`（逐题、考点时间轴数据）→ `v3_html.py`（页面）。官方文件和解读放 `bank/guides/official-<考试>-<科目>-<地区>.json`（docs、news 两部分）。第一份初级版是成都中考数学。

## 1. 一句话标准

一个对整体情况不熟的普通考生，**一分钟看完就知道：这张卷什么样、分在哪、先抓什么、今年要留意什么变化。**

## 2. 输出：两条主轴，先把数据和信息看清楚

用户 2026-11-13 定：这一层先做数据清洗和可视化，深度分析以后再做。不做立体效果，不放「老师划重点」。

| 部分 | 怎么呈现 | 要回答的问题 |
|---|---|---|
| 按试卷看：几年对照 | 一张真实试卷的样子，按大题和题号排。每个题号一行，横着是近几年：上面是考点，连续几年考同一考点的格子连成一块；下面是每年的难度 | 这道题号这几年考什么、难度怎么变？ |
| 按试卷看：点开一题 | 选年份看那一年的原题图、考点、难度、分值、小问考点 | 这道题实际长什么样？ |
| 按试卷看：单年真题 | 选某一年，整张卷按真卷顺序显示每题原题图和标签 | 那一年的卷子是什么样？ |
| 按考点看 | 按年级、学期、章节排成时间轴，列出全部考点（没考过的也列，标灰）。每个考点：近几年每年考没考、多难（色块），考到时平均分，题数，占几年总分的比例；顶部是各册分数占比。可切换按分值排序 | 每一册、每个考点考多少、考多深？ |
| 按考点看：点开 | 列出每次考到的年份、题号、小问、分值、难度，点了跳到那一年那道原题 | 这个考点在哪些题里考过？ |
| 考频小标签（按试卷看） | 每个题号上方一行小圆点标签：考点固定 n/m、同一块内容、每年换考点、一直基础/中档/难、近两年变难/变容易、某年新考点。只给结论，不写大段文字 | 这道题稳不稳、高频还是低频？ |
| 考点的册别和领域 | 每格考点下标在哪一册学（如「九下」），底色区分数与代数、图形与几何、统计与概率 | 这个考点哪一阶段学的？ |
| 考点筛选（按考点看） | 全部、近 5 年都考、近 4 年都考、近 5 年常考、偶尔考、一直没考过，并可按领域筛；每个考点直接露出考过的题号 | 快速找出常考或没考过的考点 |
| 年份范围 | 用该地区全部年份；按题号对照只用卷面结构和最新一年相同的年份，并留一列给下一年（待出） | — |
| 看走势（第三个页签） | 升温、降温考点和各大块分数变化 | 今年要多留意什么？ |
| 官方文件 | 当地考试院、教育局的文件：名称、发布单位、日期、原文链接、要点摘录，以及可展开的原文全文（网页正文 + 图片文字识别，图片原件本地存档）。不交互 | 官方规定是什么？ |
| 命题解读 | 每年中考后公开发布的专家解读：要点、原文链接和可展开的原文全文。不交互 | 官方怎么评这几年的卷？ |

## 3. 不放什么

- 统计口径的细节：主考点、次考点、分值怎么拆、覆盖率、待核标签。这些留在数据里，审核页能看，考生版不放。
- 学术分类：认知要求、核心素养、情境类别。它们留着给系统做个性化，不直接给考生看。
- 没有来源的数字：比如考试时长，卷面和官方文件都没找到之前不放。

## 4. 计算规则（考生版）

| 项目 | 规则 |
|---|---|
| 统计范围 | 最近 5 年原卷；同一年多套卷时只取一套，并在审核页写明 |
| 考点分值 | 主考点记分，可疑标签（Jev 核对低于 0.3）剔除后再算 |
| 重点排序 | 考了几年 ÷ 5 × 考到那年的平均分 |
| 分档 | 必拿：5 年考了至少 4 年，且主要难度是易或中；攻坚：至少 4 年，主要是难；常考：2–3 年；偶考：1 年 |
| 趋势 | 比较最近 2 年和之前 3 年：平均分高出满分的 3%（至少 3 分）为升温；低这么多为降温；只在近 2 年出现为新出现；之前至少 2 年考、近 2 年没考为近两年没考 |
| 卷面路线 | 按最近一年卷面的题型顺序切段；卷面有「B 卷」标题时分 A、B 卷；每段的常考考点和难度按 5 年合计 |
| 分数结构 | 按小问难度和分值算，换算成满分里的分数 |
| 年级册别 | 知识点 → 教材章节对应表（`bank/kp-textbook.json`），目前只有人教版初中数学，Jev 判断、人工复核 |
| 题位档案 | 按最近一年卷面的题号，看每个题号几年分别考了什么：同一考点出现在除一年外的所有年份为题位固定；同一模块为模块固定；8 分以上、考点出现 3 种以上为题材轮换 |
| 老师划重点 | 解答题中题位固定的合计分；分值不超过 6 分但几乎年年难的题；选择、填空里几乎年年中档的题（易被当送分题）；最后一道解答题的题材变化；升温考点 |

## 5. 输入清单

| 输入 | 现状 | 缺口 |
|---|---|---|
| 近 5 年原卷、每题考点和分值 | 有 | 回忆版、缺年要在来源一行写明 |
| 小问难度 | 有，AI 判断 | 没有和真实得分率对过 |
| 考点核对 | 有（Jev） | 全库还没跑 |
| 年级、册别 | 人教版初中数学 | 其他科、其他教材版本（各地教材不同） |
| 卷面结构（A、B 卷） | 从卷面大题标题读 | — |
| 官方信息（考试说明、时长、命题变化） | 没有系统采集 | 归信息源层 |

## 6. 给个性化留的接口

每个考点输出：分档、趋势、年级册别、平均分、考了几年。以后接学生数据时：没学过的先放下，已学未掌握的按分档和趋势排；整份指南不用改结构。

数据来源：地区考情统计表（`bank/region-stats/`，结构见 docs/13 第 9 节）。页面里的考频、趋势、题号稳定性都读这张表，不在页面里另算。
