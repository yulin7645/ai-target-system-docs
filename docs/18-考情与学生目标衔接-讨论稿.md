# 目标、得分计划、学情：三块积木怎么衔接（v3，已定）

> 2026-11-14 用户定。v2 里「学情改得分计划的排序」作废：两块互相改写，不好控制。复习计划先放一放。

## 0. 一句话

**得分计划只认目标分，学情只给概率，调目标由学生来做。** 三块之间只有单向的数据流，没有自动回路。

## 1. 顺序和数据流

```
目标（M1）──每科 S / A / B──▶ 得分计划 ──每档要拿下哪些题──▶ 达成评估 ◀── 学情
                                   ▲                              │
                                   │                              ▼
                                   └──── 学生自己调目标 ◀── 「达成 A 的概率 85%」
```

| 顺序 | 积木 | 输入 | 输出 | 说明 |
|---|---|---|---|---|
| 1 | 目标 | 志愿线、成绩、兴趣信心 | 每科三档 S / A / B | 到这里就结束了，信心等中间量不再往下传 |
| 2 | 得分计划 | **只有每科的目标分**（加上地区考情，这是资料资产，不是学生输入） | 每一档要拿下哪些题、哪些考点 | 同一地区、同一目标分，算出来的计划一样，可复现 |
| 3 | 学情 | 学生上传的试卷、考试记录 | 每个考点的掌握程度、每道题答对的概率 | 独立运行，不改计划 |
| 4 | 达成评估 | 得分计划 + 学情 | 达成 B、A、S 的概率；每档里哪些题现在还拿不稳 | 只读两边，不改任何一边 |
| 5 | 调目标 | 达成评估 | 新的目标分 → 回到第 2 步 | 学生手动；以后可以自动提示，但改不改仍由学生定 |

## 2. 得分计划

- **入口只有一个：每科目标分（三档）。** 来自目标模块，也可以是学生直接填的数。
- **按题号拆：** 从最好拿的题开始累加，累到 B 的是保底档，接着累到 A 的是目标档，再到 S 的是冲刺档，剩下可以放。每道题带上常考考点和在哪一册学。
- **「好不好拿」按一般学生估：** 基础 0.8、中档 0.5、难 0.2（目标模块已在用的系数），以后可以换成真实得分率。和具体学生无关。
- **它是一张标准路线：** 「在成都，数学要考 120，一般是这样拿分的」。

## 3. 学情和达成评估

- 学情对每道题算出这个学生答对的概率（docs/09 第 3.4 节的模型）。
- 达成评估把这些概率放到得分计划上，算两样东西：
  1. **达成每一档的概率：** 用每道题的概率算出总分的分布，看总分达到 B、A、S 的可能性各有多大。
  2. **每档里的薄弱题：** 计划要求拿下、但这个学生答对概率低的题，就是现在最该补的地方。
- 概率要带上依据的多少，比如「依据：1 次月考」。前期证据少，只说倾向。

## 4. 调目标

- 学生看到「达成 A 的概率 85%，达成 S 的概率 40%」，可以自己把目标调高，得分计划随之重算。
- 以后可以自动提示，沿用目标模块已有的规则：连续两次考试达成概率明显高于或低于目标时，提示「要不要调整目标」，学生确认才改。

## 5. 为什么这样更可控

| | v2（作废） | v3（现在） |
|---|---|---|
| 学情变了 | 计划的排序跟着变 | 计划不变，只有概率变 |
| 同一目标的计划 | 每个学生不一样 | 一样，可复现、好检查 |
| 模块关系 | 学情改写得分计划 | 单向：学情和计划都只读，评估合并 |
| 目标怎么变 | 隐含在计算里 | 学生明确地改，改了才重算 |
| 换学情算法 | 要连带检查计划 | 只影响评估结果 |

## 6. 要注意的两点

- **计划是标准路线，不是给某个学生量身定做的。** 偏科的学生（比如难题会做、基础题常错）会看到：计划里的保底题，自己的概率反而低。这正是有用的提示，不需要为他改计划。
- **自动调目标只做提示。** 如果系统自己改目标，会变成「概率高 → 目标升 → 计划变 → 概率降」的循环，结果来回摆。保持「学生确认才改」，就不会出现这种情况。

## 7. 积木之间传什么

```
目标 → 得分计划：    {科目, S, A, B}
考情 → 得分计划：    [{题号, 分值, 难度, 常考考点, 册别}]
得分计划 输出：      [{题号, 分值, 档(B/A/S/可放), 考点, 册别}]
学情 输出：          {题号: 答对概率}, {考点: 掌握程度}, 依据数量
达成评估 输出：      {B: 概率, A: 概率, S: 概率}, 每档的薄弱题
```
